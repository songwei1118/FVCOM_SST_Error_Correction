# FVCOM_SST_Error_Correction
FVCOM_SST_Error_Correction is an offline deep-learning framework for correcting SST errors in FVCOM simulations. It integrates FVCOM, ERA5, and OSTIA data and compares six deep-learning architectures. The project includes model training, overall and seasonal evaluation, marine heatwave analysis, ablation experiments, and SHAP interpretation.
